# LifePilot AI

LifePilot AI is a portfolio-ready personal finance and career growth dashboard built with React, Vite, Tailwind CSS, React Router, Recharts, and LocalStorage demo data.

## Features

- Responsive SaaS landing page and protected dashboard
- Demo login and registration using LocalStorage
- Dark and light mode
- Finance cards, transaction form, filters, charts, and savings goal progress
- Career profile, skills, missing skills, application tracker, and progress score
- Resume analyzer with mock AI feedback
- AI advisor with context-aware demo responses
- Settings for profile, currency, language, and theme
